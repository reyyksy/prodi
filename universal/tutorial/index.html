Konfigurasi dan akses

Yang wajib diganti sebelum instalasi nyata: SESSION_SECRET (teks acak minimal 32 karakter), ADMIN_DEFAULT_USER, dan ADMIN_DEFAULT_PASS. PORT boleh tetap 3000 jika tidak bentrok.

PORT=3000
SESSION_SECRET=buat-teks-acak-minimal-32-karakter
ADMIN_DEFAULT_USER=admin-baru
ADMIN_DEFAULT_PASS=password-kuat-baru

Clone development saat ini memakai login sementara admin / admin12345. Restart menyelaraskan password dari .env ke database. Form ganti password admin juga memperbarui .env. Clone release memakai .env.example sebagai template. Jangan commit atau membagikan .env.

Edit config/site.js untuk sekolah/logo dan config/paslon.js untuk calon. Buka pemilih di http://localhost:3000/?pc=1 sampai ?pc=5.

Cek server dari terminal

Di folder development /home/reihan/repo/me/prodi1/prodi, jalankan node --version, npm --version, npm run check, npm run init-db, lalu npm start. Di terminal kedua jalankan curl http://localhost:3000/api/health dan curl http://localhost:3000/api/public/election-status. Health yang benar memuat "server_running":true. PowerShell dapat memakai Invoke-WebRequest http://localhost:3000/api/health. Hentikan dengan Ctrl+C.

Mode online sementara

Buka http://localhost:3000/online/. Di komputer server, salin online/.env.example menjadi online/.env dan isi lima akun client resmi. File online/.env hanya dibaca server. Frontend online memakai backend dan database yang sama, client dibatasi satu kali memilih, sedangkan pilihan suara tetap tidak disimpan bersama identitas client. Admin online tetap masuk melalui /admin.html.

Forward hanya port online

Jalankan satu perintah npm start. Backend port 3000 dan frontend online port 4000 otomatis berjalan bersamaan. Forward port 4000 saja melalui VS Code. Buka halaman utama untuk client, /admin.html untuk admin, dan /statistik.html untuk monitoring. Port 4000 meneruskan API ke backend port 3000.

Development dan release untuk GitHub

Perubahan dikerjakan di /home/reihan/repo/me/prodi1/prodi. Hasil final disiapkan di clone fresh /home/reihan/repo/me/prodi. Ulangi npm install, npm run check, npm run init-db, dan npm start di clone release sebelum commit dan push. Jangan menyalin node_modules, data, backups, exports, atau .env.

Konfigurasi pusat

Gunakan satu file utama config/paslon.js untuk identitas sekolah, judul, logo, kandidat, visi, misi, dan proker. Setelah mengubahnya, jalankan npm run init-db.
