1. Alat yang Harus Diinstal di Komputer (Prerequisites)

Jika komputer baru atau komputer sekolah yang Anda gunakan belum terpasang aplikasi pendukung, cukup instal 2 alat dasar berikut (tidak memerlukan database MySQL/XAMPP):

Software / Tools Fungsi Cara Download / Install
Git Untuk mengunduh (clone) repositori dari GitHub. • Windows: Unduh file instalasi di git-scm.com.
• Linux: sudo apt update && sudo apt install -y git
Node.js (LTS) Runtime backend JavaScript untuk menjalankan aplikasi server dan SQLite bawaan. • Windows: Unduh installer LTS di nodejs.org (klik Next hingga selesai).
• Linux: curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs
Pemeriksaan: Buka Command Prompt (Windows) atau Terminal (Linux) dan ketik: 
git --version
node -v
npm -v

2. Cara Clone & Langsung Pakai (Tanpa Ribet Konfigurasi .env)

Aplikasi ini telah dirancang zero-configuration. Anda TIDAK PERLU membuat atau mengubah file .env secara manual. Semua nilai default sudah otomatis terkonfigurasi di dalam sistem.

  1. Buka Terminal / Command Prompt lalu Clone Repositori: 
    git clone https://github.com/reyyksy/prodi.git
  2. Masuk ke Folder Proyek: 
    cd prodi
  3. Instal Dependensi (Hanya 1 Perintah): 
    npm install

    Sistem otomatis mengunduh express, better-sqlite3, dan exceljs.

3. Cara Menjalankan Server di Windows & Linux (Non-Root)

Aplikasi berjalan pada user biasa tanpa butuh akses root / administrator khusus:

Di Windows (Command Prompt / PowerShell):

npm start
# Atau:
node server.js

Di Linux / macOS:

npm start
# Atau:
node server.js

4. Pengaturan Jaringan LAN & Bilik PC 1 s.d. PC 5

Sistem ini dirancang untuk berjalan di LAN Lab Komputer SMKS Yasbam tanpa membutuhkan internet:

  1. Hubungkan Komputer Server dan 5 unit PC Bilik Siswa ke Switch/WiFi yang sama.
  2. Buka Browser (Google Chrome / Edge) pada masing-masing PC bilik suara siswa:
    • PC Bilik 1: http://<IP-SERVER>:3000/?pc=1
    • PC Bilik 2: http://<IP-SERVER>:3000/?pc=2
    • PC Bilik 3: http://<IP-SERVER>:3000/?pc=3
    • PC Bilik 4: http://<IP-SERVER>:3000/?pc=4
    • PC Bilik 5: http://<IP-SERVER>:3000/?pc=5
  3. Tekan tombol F11 pada keyboard PC bilik untuk mengaktifkan tampilan layar penuh (Kiosk Mode).

5. Alur Kerja Panitia di Hari Pemilihan

  1. Login ke Panel Admin: Buka http://<IP-SERVER>:3000/admin.html pada laptop/komputer panitia.
  2. Buka Pemilihan: Klik tombol hijau "Mulai / Buka Pemilihan". Status server dan bilik akan beralih menjadi OPEN.
  3. Pengawasan Bilik: Siswa masuk dan mencoblos. Setelah siswa selesai, bilik akan menampilkan layar konfirmasi terima kasih dan status PC di admin berubah menjadi "Sudah Memilih - Menunggu Panitia".
  4. Siapkan Pemilih Berikutnya: Panitia mengklik tombol "Siapkan Pemilih Berikutnya" pada PC yang bersangkutan di menu Monitoring PC. Layar bilik siswa akan otomatis reload ke awal dan siap digunakan siswa berikutnya.
  5. Penutupan & Ekspor Excel: Setelah waktu pemilihan usai, klik "Tutup (Final)", lalu buka tab Backup & Ekspor untuk mengunduh laporan resmi dalam format Excel (.xlsx).

6. Arti Indikator Status Server di Halaman Admin

Halaman admin dilengkapi indikator teks dan warna yang sangat mudah dipahami:

  • 🟢 Server Hidup • Pemilihan Buka (OPEN): Server berjalan normal dan bilik suara sedang menerima pemungutan suara dari siswa. Banner hijau akan tampil menginformasikan server aktif.
  • 🟠 Server Hidup • Pemilihan Dijeda (PAUSED): Server berjalan lancar, namun voting dihentikan sementara oleh panitia (siswa di bilik tidak dapat mengirim suara sebelum dibuka). Banner kuning akan tampil dengan tombol pintas untuk membuka pemilihan.
  • 🔴 Server Hidup • Pemilihan Ditutup (CLOSED): Pemilihan telah selesai secara final. Seluruh suara telah terkunci sah dan siap diekspor ke Excel.
  • ❌ Server Belum Jalan / Mati (OFFLINE): Browser tidak dapat menghubungi backend Node.js. Banner merah peringatan akan muncul meminta Anda menjalankan node server.js di terminal.

7. Panduan Menghadapi Kendala (Troubleshooting)

Perlindungan Listrik Padam / Server Ter-Restart (Safety Recovery Mode):

Jika terjadi mati lampu saat pemilihan sedang OPEN, sistem secara otomatis mengalihkan status ke PAUSED (dijeda) begitu komputer menyala kembali. Banner oranye "STATUS PEMULIHAN LISTRIK / RESTART" akan muncul di panel admin. Panitia cukup memastikan koneksi 5 bilik PC lalu mengklik "Mulai / Buka Pemilihan" untuk melanjutkan.

Snapshot Statistik 15 Menit di Halaman Publik:

Halaman /statistik.html menggunakan snapshot interval 15 menit agar reload/refresh browser yang tidak sengaja tidak mengubah perolehan suara secara sembarangan. Data teragregasi secara otomatis sesuai jadwal sistem.
