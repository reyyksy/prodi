Panduan Prodi E-Voting

Panduan ini sama dengan tutorial visual dan README. Aplikasi berjalan di Windows 10/11, Linux, dan macOS dengan Node.js LTS 20/22.

1. Instalasi Windows PowerShell

git clone https://github.com/reyyksy/prodi.git
Set-Location prodi
npm install
Rename-Item .env.example .env
notepad .env
npm run init-db
npm start

2. Instalasi Linux

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
mv .env.example .env
nano .env
npm run init-db
npm start

3. Instalasi macOS

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
mv .env.example .env
nano .env
npm run init-db
npm start

4. Konfigurasi

Perintah instalasi mengubah nama .env.example menjadi .env. Isi .env dengan port, rahasia sesi acak minimal 32 karakter, username admin, dan password admin yang kuat. Jangan commit file ini.

Untuk identitas, edit config/site.js. Untuk nama, foto, nomor, visi, misi, dan program calon, edit config/paslon.js. Simpan gambar di public/images/.

5. Membuka aplikasi

Pemilih: http://localhost:3000/. Admin: /admin.html. Statistik: /statistik.html. Tutorial: /tutorial/index.html. Dari LAN gunakan http://IP-SERVER:3000/ dan izinkan Node.js di firewall.

6. Data dan masalah umum

Database berada di data/election.sqlite, backup di backups/, dan ekspor di exports/. Hentikan server dengan Ctrl+C. Jalankan npm run check untuk pemeriksaan sintaks. Jika port bentrok, ubah PORT di .env. Database memakai sql.js sehingga tidak membutuhkan compiler.

Error Cannot find module './auth'

Ini berarti file proyek src/auth.js tidak ada di working tree, bukan dependency yang belum diinstal. Periksa git status --short; jika tertulis D src/auth.js, pulihkan file tersebut dengan menjalankan git restore src/auth.js dari folder proyek, lalu ulangi npm run init-db atau npm start. Perintah npm install tidak akan membuat file sumber yang terhapus.
