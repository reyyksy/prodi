Panduan Prodi E-Voting

Panduan ini sama dengan tutorial visual dan README. Aplikasi berjalan di Windows 10/11, Linux, dan macOS dengan Node.js LTS 20/22.

1. Instalasi Windows PowerShell

git clone https://github.com/reyyksy/prodi.git
Set-Location prodi
npm install
Rename-Item .env.example .env
notepad .env
npm run init-db
npm start

2. Instalasi Linux

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
mv .env.example .env
nano .env
npm run init-db
npm start

3. Instalasi macOS

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
mv .env.example .env
nano .env
npm run init-db
npm start

4. Konfigurasi .env

Yang wajib diganti sebelum dipakai sungguh-sungguh: SESSION_SECRET dengan teks acak minimal 32 karakter, ADMIN_DEFAULT_USER, dan ADMIN_DEFAULT_PASS. PORT=3000 boleh tetap jika tidak bentrok; ubah jika perlu. Jangan commit file .env.

PORT=3000
SESSION_SECRET=buat-teks-acak-minimal-32-karakter
ADMIN_DEFAULT_USER=admin-baru
ADMIN_DEFAULT_PASS=password-kuat-baru

Clone development saat ini memakai login sementara admin / admin12345. Restart menyelaraskan password dari .env ke database, dan form ganti password admin memperbarui .env. Clone release menggunakan .env.example sebagai template.

Untuk identitas, edit config/site.js. Untuk calon, edit config/paslon.js.

5. Membuka aplikasi

Pemilih: http://localhost:3000/. Admin: /admin.html. Statistik: /statistik.html. Tutorial: /tutorial/index.html. Dari LAN gunakan http://IP-SERVER:3000/ dan izinkan Node.js di firewall.

6. Cek server dari terminal

Di folder development /home/reihan/repo/me/prodi1/prodi, jalankan node --version, npm --version, npm run check, npm run init-db, lalu npm start. Pada terminal kedua jalankan curl http://localhost:3000/api/health dan curl http://localhost:3000/api/public/election-status. Respons health harus memuat "server_running":true. PowerShell dapat memakai Invoke-WebRequest http://localhost:3000/api/health. Hentikan dengan Ctrl+C; jika port bentrok, ubah PORT di .env.

Error Cannot find module './auth'

Ini berarti file proyek src/auth.js tidak ada di working tree. Periksa git status --short; jika tertulis D src/auth.js, jalankan git restore src/auth.js.

7. Development dan clone release

Perubahan dikerjakan di /home/reihan/repo/me/prodi1/prodi. Hasil final disiapkan di clone fresh /home/reihan/repo/me/prodi untuk commit dan push GitHub. Di clone release ulangi instalasi dan semua pengecekan sebelum push. Jangan menyalin node_modules, data, backups, exports, atau .env.
