Tutorial Prodi E-Voting

Panduan ini sama dengan panduan utama dan README.

Windows PowerShell

git clone https://github.com/reyyksy/prodi.git
Set-Location prodi
npm install
Copy-Item .env.example .env
notepad .env
npm run init-db
npm start

Linux

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
cp .env.example .env
nano .env
npm run init-db
npm start

macOS

git clone https://github.com/reyyksy/prodi.git
cd prodi
npm install
cp .env.example .env
nano .env
npm run init-db
npm start

Konfigurasi dan akses

Isi .env dengan PORT, rahasia sesi acak minimal 32 karakter, username, dan password admin kuat. Edit config/site.js untuk sekolah/logo; edit config/paslon.js untuk calon/foto/visi/misi/program. Buka pemilih di http://localhost:3000/, admin di /admin.html, statistik di /statistik.html. LAN memakai http://IP-SERVER:3000/.

Data dan troubleshooting

Database: data/election.sqlite; backup: backups/; ekspor: exports/. Hentikan dengan Ctrl+C. Gunakan npm run check. Jika port bentrok ubah PORT; jika LAN gagal periksa firewall. sql.js tidak membutuhkan compiler.
