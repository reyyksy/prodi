SERVER AKTIF & PEMILIHAN DIBUKA (OPEN)

Server Node.js berjalan lancar di port 3000. Bilik suara PC 1-5 siap menerima pencoblosan dari siswa.

SERVER AKTIF TETAPI PEMILIHAN SEDANG DIJEDA (PAUSED)

Server hidup dan terhubung ke database, namun voting saat ini dihentikan sementara (siswa di bilik tidak dapat mengirim suara sebelum dibuka).

STATUS PEMULIHAN LISTRIK / RESTART (SAFETY RECOVERY MODE)

Komputer server baru saja menyala kembali setelah mati lampu atau restart saat pemilihan sebelumnya berstatus OPEN. Demi keamanan data dan mencegah coblos ganda, sistem otomatis beralih ke DIJEDA (PAUSED).

Silakan pastikan bilik PC pemilih telah terhubung kembali, lalu tekan tombol "Mulai / Buka Pemilihan" untuk melanjutkan pemungutan suara.

SERVER BELUM JALAN ATAU MATI (OFFLINE)

Aplikasi browser tidak dapat terhubung ke backend Node.js. Silakan buka terminal / Command Prompt di komputer server lalu ketik perintah: node server.js (sebagai pengguna biasa, kompatibel di Windows maupun Linux).
